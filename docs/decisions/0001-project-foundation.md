# 0001：项目重建基础

确认日期：2026-09-14。本文记录选择及原因；具体范围、实现约定与验收结果由 [文档索引](../index.md) 中的对应文档维护。

## 原仓库从零重建

沿用当前 Git 仓库，在新分支创建应用并保留历史。这遵循用户“完全重新新建项目”和“沿用当前仓库”的要求；旧实现与旧产品文档不自动成为新需求。技术栈已逐项确认，见 [架构说明](../architecture.md)。

## 静态生成与 Cloudflare Pages

当前公开介绍与静态内容适合 SSG：构建时生成 HTML，浏览器继续处理主题切换等交互，不需要请求时运行 Nuxt 服务端。沿用现有 Cloudflare Pages 项目与域名，具体配置见 [部署说明](../release.md)。

若以后出现实时个性化或服务端业务，再评估按路由混合渲染，并同时更新构建与部署配置。

## 主题与资源统一管理

颜色、字体和基础样式统一使用 npm 正式发布的 `@ayingott/theme`，让视觉调整由主题资源承载。应用直接消费语义变量与字体角色，接入方式见 [架构说明](../architecture.md)。原简历 PDF 是用户明确要求保留的资源，保留要求见 [产品要求](../specs/requirements.md)。

## 工程与首页原型分阶段推进

先验证工程、主题、静态构建和真实 Cloudflare 预览，再实现首页原型与正式内容。临时介绍页用于工程验证，作品、文章和介绍文案仍按 [产品要求](../specs/requirements.md) 中的待定事项处理。
