# 0003：采用技能中的目录约定

日期：2026-09-15。状态：已采用，替代 [0002 中的目录分组约定](0002-documentation.md)。

## 背景

用户要求按 `agent-config-setup` 的 `references/docs/index.md` 目录约定再次调整。之前的产品、工程分组混合了承载不同职责的文档；开发与部署中也重复列出了通用验证步骤。

## 采用方式

目录与内容维护规则统一收录在 [文档索引](../index.md#目录约定)，以本次读取的技能模板为依据。

- 全局结构、模块职责和共享约束归入 [architecture.md](../architecture.md)。
- 环境准备、编码约定、日常检查和本地预览归入 [development.md](../development.md)。
- Cloudflare 构建配置、发布流程与发布后验证归入 [release.md](../release.md)，引用开发文档维护的共用方法与脚本。
- 重建要求与页面设计归入 `specs/`；简短理由随规格维护，需要追溯的独立决策保留在 `decisions/`。

模板允许保留合理的既有结构，因此继续使用 `verification/` 保存实际验收记录，按日期和验收对象归档。已有官方资料链接保留在相关文档中，待有独立资料正文时再建立 `references/`。

## 维护边界

本次调整文档归属和引用，沿用已确认的产品范围、技术选择与验收结论。历史记录保留当时的数据；被替代的目录决策指向本文。
