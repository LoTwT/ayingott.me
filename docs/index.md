## 维护约定

- 同一项知识只在一处维护，其他位置引用。全局结构写在架构文档，具体功能写在对应规格，日常方法写在开发约定。
- 改动代码时同步更新受影响的文档；文档只描述当前状态，不记录过程与历史，历史以 Git 为准。
- 新增文档平铺在 `docs/` 下，专项规格放在 `specs/`，并在本索引登记。

通用 Agent 工作规则见 [AGENTS.md](../AGENTS.md)。精确依赖与命令以 [package.json](../package.json) 为准，Node 版本见 [.node-version](../.node-version)。
