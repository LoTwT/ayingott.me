# 产品要求

更新日期：2026-09-16。

沿用 `ayingott.me` 当前 Git 仓库，在新分支从零创建应用，保留历史。目标是极简、清楚、简单、干净；旧站的页面和功能不作为新站范围。

## 首轮交付

- 使用已确认的技术栈建立工程，具体组成与实现约定见 [架构说明](../architecture.md)。
- 接入 npm 正式发布的 `@ayingott/theme`，验证字体与明暗主题。
- SSG 构建，部署仍使用 Cloudflare，域名不变。
- 完成 lint、格式、类型、静态构建、本地 Cloudflare 预览与真实线上预览验证。
- 核对旧 Cloudflare 构建设置，提供需要修改的具体配置。
- 当前 [public/resume.pdf](../../public/resume.pdf) 原样留在新项目 `public` 中，用户提供替代文件前保持字节不变；验证 `/resume.pdf` 可访问。

当前界面为首页结构原型，包含临时介绍、主题切换、首屏下方的少量作品与文章示例，并保留错误恢复入口。示例只用于确认布局，不代表分类已经确定。页面不展示简历入口，PDF 仍按上述要求保留。首轮验收当时的完成情况与待验证事项见 [验收记录](../verification/2026-09-14-foundation.md)。

## 未定事项与范围边界

- 作品和文章只是分类示例，尚未确定是否加入。
- 当前不加入内容接入系统、作品或博客页面及额外个人经历文案。图标库已确认，选型见 [架构说明](../architecture.md)，主题按钮行为见 [设计方向](design.md)。

本轮交付本地可运行的首页原型，使用现有检查、静态构建与真实浏览器验证，不新增长期验收脚本。正式内容、分类与生产发布留待后续确认。布局约束和待定设计见 [设计方向](design.md)。改变范围前更新本文；选择的原因记录在 [项目决策](../decisions/0001-project-foundation.md)。
