# 产品要求

更新日期：2026-10-09。

沿用 `ayingott.me` 当前 Git 仓库，在新分支从零创建应用，保留历史。目标是极简、清楚、简单、干净；旧站的页面和功能不作为新站范围。

## 首轮交付

- 使用已确认的技术栈建立工程，具体组成与实现约定见 [架构说明](../architecture.md)。
- 接入 npm 正式发布的 `@ayingott/theme`，验证字体与明暗主题。
- SSG 构建，部署仍使用 Cloudflare，域名不变。
- 完成 lint、格式、类型、静态构建、本地 Cloudflare 预览与真实线上预览验证。
- 核对旧 Cloudflare 构建设置，提供需要修改的具体配置。
- 当前 [public/resume.pdf](../../public/resume.pdf) 原样留在新项目 `public` 中，用户提供替代文件前保持字节不变；验证 `/resume.pdf` 可访问。

当前首页包含介绍、主题切换、首屏文案下方的 GitHub、邮箱与简历三个图标入口及页脚，并保留错误恢复入口。入口均已由用户确认；具体展示与交互见 [设计方向](design.md)。简历入口使用现有 PDF，文件仍按上述要求保留。首轮验收当时的完成情况与待验证事项见 [验收记录](../verification/2026-09-14-foundation.md)。

站点图标、页面标题与描述、链接分享卡片纳入当前原型，沿用已确认的姓名、介绍、入口与域名，视觉方案见 [站点标识与分享初版](design.md#站点标识与分享初版)。

## 生产状态与站点维护

当前首页已通过 `main` 的 Cloudflare Git 集成发布到生产域名，核对结果见 [验收记录](../index.md#验收记录)。

- 旧站的 `/about`、`/works`、`/blog` 及其下的文章地址已移除，不做跳转，访问时显示 404 页并提供回到首页的入口。
- 提供 `robots.txt` 与仅含首页的 `sitemap.xml`；首页附带描述本人的 schema.org `Person` 结构化数据。
- 页脚年份在构建时确定，跨年后需重新构建发布才会更新。

具体文件与实现位置见 [架构说明](../architecture.md#公开资源)。

## 范围边界

- 不加入作品、文章或博客页面，不接入内容系统，首页不补充介绍说明或个人经历文案。
- 图标库已确认，选型见 [架构说明](../architecture.md)，主题按钮行为见 [设计方向](design.md)。

首轮交付使用现有检查、静态构建与真实浏览器验证，不新增长期验收脚本。布局约束见 [设计方向](design.md)。改变范围前更新本文；选择的原因记录在 [项目决策](../decisions/0001-project-foundation.md)。
