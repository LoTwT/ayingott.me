# 产品要求

站点目标是极简、清楚、干净的个人主页与文章。旧站的页面和功能不作为新站范围。

## 页面

- **首页**：Header 中的站点导航与主题切换、介绍、GitHub、邮箱与简历三个图标入口、页脚。见 [设计方向](design.md)。
- **文章**：`/posts` 列表、文章页与 `/tags/<tag>` 标签页，支持标签、RSS 与每篇文章的分享卡片，不设草稿与分类。见 [文章发布](articles.md)。
- **错误页**：404 与其他错误提供回到首页的入口。旧站的 `/about`、`/works`、`/blog` 已移除，不做跳转。

## 约束

- [public/resume.pdf](../../public/resume.pdf) 原样保留，用户提供替代文件前保持字节不变，`/resume.pdf` 必须可访问。
- 不加入作品页面，首页不补充介绍说明或个人经历文案；首页图标入口只承载个人信息，站内页面入口放在 Header 导航。
- 提供 `robots.txt`、构建时生成的 `sitemap.xml` 与 `feed.xml`；首页输出 schema.org `Person`，文章页输出 `BlogPosting` 结构化数据。
- 页脚年份在构建时确定，跨年后需重新构建发布才会更新。

改变范围前更新本文，实现位置见 [架构说明](../architecture.md)。
