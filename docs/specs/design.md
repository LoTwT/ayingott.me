# 设计方向

更新日期：2026-10-02。

## 已选布局

首屏在桌面和手机均承载个人介绍，联系方式与简历入口以图标放在介绍文案下方。采用已选布局 1：短文案左对齐、略高于垂直中心。当前没有其他分类内容，暂不渲染。Header 放主题切换，不放左上文字标识。不提供 RSS。

主题切换入口采用 Lucide 图标按钮：显示器表示跟随系统，太阳表示浅色，月亮表示深色。图标表达已选择的偏好；跟随系统时保持显示器图标，页面明暗由系统决定。

点击单个按钮按“跟随系统 → 浅色 → 深色 → 跟随系统”循环切换，不展开菜单。按钮的提示文字与可访问名称说明当前偏好和下次点击的目标；支持 Enter/Space 激活。刷新时从首次显示起呈现已保存偏好对应的图标，不先显示“跟随系统”图标再替换；客户端确定偏好前按钮暂时禁用。

主题按钮背景保持透明，悬停时图标从次要文字色变为主要文字色。点击区域为 44 × 44 px，键盘操作时显示焦点提示。

主题切换动效（柔和光幕，已确认）：实际明暗变化时，旧画布色在内容下方形成边缘柔化的背景光幕，用 600ms 退开并露出新背景：浅色切到深色时向左，深色切到浅色时向右；选择“跟随系统”时按实际明暗变化决定方向。标题与页脚等文字使用与背景对齐的文字渐变，让同一行字的两侧随光幕分别换色；图标与链接按各自水平位置换色。两者与光幕共用时长、曲线及渐变边缘宽度。光幕不再盖住文字，也不再让整页文字提前用 180ms 完成换色。正文、链接、页脚和 Header 均保持原位；主题图标形状仍在原位用 180ms 交替淡入淡出。

光幕限制在视口内，不拦截点击，结束后移除。偏好改变但实际明暗不变时，仅有图标过渡。主题偏好立即更新；连续切换明暗时结束上一次动效并开始新方向，不排队叠加。刷新和系统配色自动变化不触发动效，启用“减少动态效果”时直接切换。使用单层背景渐变的平移和文字、图标的颜色动画，不复制页面内容或截取整页快照。首页启用融巧背景时，分界由背景按光幕绘制，见 [首页动效](#首页动效已选)。此前轻微呼吸与圆形展开原型已撤下。

Header 独立铺满页面宽度，主题按钮不受正文内容栏的最大宽度限制。按钮点击区域右缘距视口右缘 1.5rem，640px 起为 2.5rem；默认根字号下分别为 24px 和 40px。

Footer 采用一行 `© 2026 Lo`，与正文内容栏左边界对齐，字号为 0.75rem、行高为 1.25rem，颜色使用 `--text-muted`。页脚最小高度为 5rem，文字在其中垂直居中。当前单屏内容下落在首屏底部，内容变长时随文档延伸到整页末尾。

颜色与字体来自 `@ayingott/theme`，默认视觉风格继续使用 `brutal`。

## 首页动效（已选）

背景（融巧，试做中）：首页背景是一条粗细均匀、呈 Ω 形的融合带，浅色为白巧与奶纹，深色为可可棕；奶纹层次、折边与柔和色阶形成厚度，正文、图标、Header 和 Footer 保持原位。材质与配色按独立原型“融巧 V1 · 原版”移植。原型的融合带左细右粗，右肩最粗处约为左脚的两倍，宽屏下更甚；现按到带心的屏幕距离计算粗细，抵消卷心扭曲与宽屏横向拉伸，全长保持约视口高度 15% 的一致粗细，总体分量与原型相当。外圈细缝与带身保持约视口高度 3.2% 的恒定间距，仅拱顶处略近（约 2.6%）；原型中该间距沿带忽近忽远，贴近处会让带子显细。背景铺满视口，不参与布局、不拦截指针，也不向辅助技术暴露。

构图以介绍区为锚点：介绍区中心固定落在 Ω 拱顶下方的拱内，正文相对视口越宽，Ω 放大越多（缩放不小于 0.7 倍），使 1024px 宽及以上的横屏中，融合带连同外圈细缝与介绍区保持至少 1.3 倍安全距离，正文、图标、页脚与主题按钮均不被经过。原型中的整体漂移、行进波、两组高频小波与卷心摆动已移除：它们各自独立摆动、没有方向，还会把右肩挤出尖弯；Ω 由两个固定卷心形成；右卷心转角由原型的 1.45 降为 1.0 弧度，右下转弯随之抬高、整体更舒展，最小转弯半径约为视口高度的 34%，1024px 宽及以上的横屏中呼吸张到最大时整条融合带仍在视口内，仅 768px 高的屏幕外圈细缝会贴近边缘。Ω 以介绍区为中心每 20 秒张开 3% 后收回，只从静止形状向外张开，因此不会靠近正文；材质纹理保持原型的缓慢变化。

此前的单束侧光只能靠压暗纸面显形，在浅色画布上读作污渍，已撤下；融巧以连续的材质层次显形，背景因此与正文共同构成画面。

背景由 WebGL 全屏着色器逐像素绘制。常规绘制节流到约 30fps，`requestAnimationFrame` 仍按刷新率运行，未到绘制时只检查主题切换状态；绘图缓冲区长边不超过 1350px，渲染比例不超过 1.35。首帧绘制后用 400ms 淡入；标签页隐藏时停止绘制；启用“减少动态效果”时显示静态画面，不淡入。WebGL 不可用或上下文丢失时保留主题画布色，主题切换回到上文的光幕。

切换明暗时，光幕只提供时间轴并保持不可见，背景按光幕的实时位置绘制同宽的柔化分界：旧画面被扫走，新画面随之露出，文字与图标仍按上文与光幕对齐。分界为直线；原型中 1.15 秒的弯曲分界未采用，因为文字渐变与光幕同为竖直边缘。

试做阶段的已知问题，修复前不发布：深色强度高于浅色，深色底 `#211a17` 与主题深色画布 `#191918` 不同；矮横屏（如 844×390）与手机竖屏尚未单独构图，前者正文会被经过，后者主题按钮会被经过。

联系方式与简历图标采用微磁吸：指针在链接范围内移动时，图标朝指针方向偏移，合成距离最多 3px，按住时保持偏移，离开时轻轻回到中心。偏移与复位使用 260ms 的缓出曲线，不使用回弹曲线，因为几像素的位移下回弹无法察觉。主题切换按钮采用相同反馈，但最大距离为 2px，图标交替淡入淡出和主题切换行为沿用上文约定。只移动图标内容，链接与按钮的点击区域、焦点提示和布局始终固定。磁吸仅在支持悬停的精细指针且未启用“减少动态效果”时生效；触屏和键盘保留直接操作，指针离开、失焦、指针取消、标签页隐藏或能力变化时清除偏移；按下不清除偏移，点击时图标不会额外移动。

Footer 保持静止，不添加悬停或周期性动画。版权文字只参与已有的主题颜色过渡，维持页脚的低视觉权重。

## 站点标识与分享初版

- Favicon 采用 `Lo` 字母标识，已选 [Oleo Script Regular](https://github.com/google/fonts/tree/main/ofl/oleoscript)，保留柔和的曲线和厚实的笔画，字形转为 SVG 轮廓。圆角方形底色与文字色来自主题；SVG 根据浏览器的配色偏好显示深浅版本，PNG 与手机收藏图标使用浅色版本。
- 首页浏览器标签与分享标题统一为“Lo”，描述为“Lo 的个人主页，GitHub、邮箱与简历。”，不增加未经确认的个人经历文案。
- 分享卡片采用 1200 × 630px 的米白背景，主文案为“你好，我是 Lo”，下方以弱化文字色放置 `ayingott.me`，均左对齐。中文和西文字体沿用首页，主文案末尾不加句号。

## 首页结构原型（待确认）

- 沿用最大宽度 48rem 的内容栏，手机左右留白 1.5rem，640px 起左右留白 2.5rem；图标入口采用已选 A 方案的上下结构，首个链接容器（点击热区）左缘与标题文字框左缘对齐，不使用负 margin。
- Header 高度为 6rem，介绍区至少占据扣除 Header 和 Footer 后的动态视口高度，原有底部留白为页脚腾出空间。常规视口内介绍与图标入口组成的内容组中心约在屏幕高度的 46%；低高度窗口使用紧凑的上下留白，介绍组从 Header 下方排列，避免留白产生额外滚动。窄屏或较大字号时允许介绍区自然撑高。
- 介绍采用“你好，我是 Lo”，末尾不加句号。下方暂不展示说明文字，后续有明确内容再决定是否补充。
- 标题下方依次放 GitHub、邮箱与简历三个图标链接，横向排列；GitHub 图标为 22 × 22px，信封与简历图标均为 24 × 24px、2px 描边，简历使用 Lucide `FileText`。桌面与手机的链接容器均为 36 × 36px，图标在各自容器内水平、垂直居中；GitHub 四周各留 7px，其余图标四周各留 6px，不再扩大隐形点击范围。相邻链接容器间隔 8px，图标中心相距 44px；GitHub 图标外框上缘距标题文字框下缘 13px，其余图标为 12px，作为文案的辅助入口。以上尺寸对应默认根字号，图标与容器随根字号同步缩放。
- 图标入口默认使用主题的 `--text-muted`，悬停时变为 `--text-secondary`，背景保持透明。明暗主题均沿用这组语义色，键盘操作保留焦点提示；可访问名称与原生提示文字说明链接用途，简历的可访问名称同时说明会打开新标签页。
- GitHub 使用普通网页链接，邮箱使用 `mailto:` 链接，简历提示文字为“简历（PDF）”，在新标签页打开现有 PDF 供预览；具体地址维护在 [HomeLinks.vue](../../app/components/home/HomeLinks.vue)。当前不添加其他社交入口，原作品与文章占位示例已移除。
- 当前首页仅包含首屏，移除独立链接区及其分隔线，不为未确定的作品或文章保留空白第二屏。未来若加入其他分类，仍从首屏下方开始，滚动后查看。
- 内容溢出视口或未来增加分类时，使用浏览器原生的连续滚动，允许停在任意位置；不自动吸附、不拦截滚轮或触摸事件。Header 随文档正常滚出。此前 `proximity` 试做版在小幅滚动结束后会拉回当前屏，用户指出这一体验问题，因此取消吸附。
