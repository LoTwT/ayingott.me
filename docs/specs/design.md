# 设计方向

更新日期：2026-09-16。

## 已选布局

首屏在桌面和手机均只承载个人介绍，滚动后才能看到其他分类。采用已选布局 1：短文案左对齐、略高于垂直中心。Footer 在整页末尾；当前没有 Footer 内容，暂不渲染。Header 放主题切换，不放左上文字标识。不提供 RSS。

主题切换入口采用 Lucide 图标按钮：显示器表示跟随系统，太阳表示浅色，月亮表示深色。图标表达已选择的偏好；跟随系统时保持显示器图标，页面明暗由系统决定。

点击单个按钮按“跟随系统 → 浅色 → 深色 → 跟随系统”循环切换，不展开菜单。按钮的提示文字与可访问名称说明当前偏好和下次点击的目标；支持 Enter/Space 激活。预渲染阶段显示同尺寸的禁用图标占位，客户端确定偏好后启用。

主题按钮背景保持透明，悬停时图标从次要文字色变为主要文字色。点击区域为 44 × 44 px，键盘操作时显示焦点提示。

颜色与字体来自 `@ayingott/theme`。本轮临时介绍页只用于验证工程基础，不把示例文案定为个人介绍。
