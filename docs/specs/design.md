# 设计方向

更新日期：2026-10-10。

## 已选布局

首屏在桌面和手机均承载个人介绍，联系方式与简历入口以图标放在介绍文案下方。采用已选布局 1：短文案左对齐、略高于垂直中心。Header 左侧放站点导航，右侧放主题切换，不放文字标识，导航见 [站点导航](#站点导航已选)。

主题切换入口采用 Lucide 图标按钮：显示器表示跟随系统，太阳表示浅色，月亮表示深色。图标表达已选择的偏好；跟随系统时保持显示器图标，页面明暗由系统决定。

点击单个按钮按“跟随系统 → 浅色 → 深色 → 跟随系统”循环切换，不展开菜单。按钮的提示文字与可访问名称说明当前偏好和下次点击的目标；支持 Enter/Space 激活。刷新时从首次显示起呈现已保存偏好对应的图标，不先显示“跟随系统”图标再替换；客户端确定偏好前按钮暂时禁用。

主题按钮背景保持透明，悬停时图标从次要文字色变为主要文字色。点击区域为 44 × 44 px，键盘操作时显示焦点提示。

主题切换动效（柔和光幕，已确认）：实际明暗变化时，旧画布色在内容下方形成边缘柔化的背景光幕，用 600ms 退开并露出新背景：浅色切到深色时向左，深色切到浅色时向右；选择“跟随系统”时按实际明暗变化决定方向。标题与页脚等文字使用与背景对齐的文字渐变，让同一行字的两侧随光幕分别换色；图标与链接按各自水平位置换色；文章正文中的列表项与公式也按各自水平位置换色，避免列表符号与公式的线条在文字渐变期间消失。两者与光幕共用时长、曲线及渐变边缘宽度。带底色或边框的块（代码块与行内代码的底色、图片边框、表格线、分隔线、引用左边线）随主题立即切换，不跟随光幕。光幕不再盖住文字，也不再让整页文字提前用 180ms 完成换色。正文、链接、页脚和 Header 均保持原位；主题图标形状仍在原位用 180ms 交替淡入淡出。

光幕限制在视口内，不拦截点击，结束后移除。偏好改变但实际明暗不变时，仅有图标过渡。主题偏好立即更新；连续切换明暗时结束上一次动效并开始新方向，不排队叠加。刷新和系统配色自动变化不触发动效，启用“减少动态效果”时直接切换。使用单层背景渐变的平移和文字、图标的颜色动画，不复制页面内容或截取整页快照。此前轻微呼吸与圆形展开原型已撤下。

Header 独立铺满页面宽度，主题按钮不受正文内容栏的最大宽度限制。按钮图标的右缘距视口右缘 1.5rem，640px 起为 2.5rem，与窄屏下内容栏文字的右边线一致；44 × 44px 的点击区域在图标外侧对称扩展。

Footer 采用一行 `© <年份> Lo`，年份取构建时的年份（当前为 2026），与正文内容栏左边界对齐，字号为 0.75rem、行高为 1.25rem，颜色使用 `--text-muted`。页脚最小高度为 5rem，文字在其中垂直居中。当前单屏内容下落在首屏底部，内容变长时随文档延伸到整页末尾。

颜色与字体来自 `@ayingott/theme`，默认视觉风格继续使用 `brutal`。

## 首页动效（已选）

背景保持静止，不添加常驻的装饰光影。浅色画布接近纸白，光影只能靠压暗周围才能被察觉，压暗部分在纸面上读作污渍并抢走正文的视觉重心，明暗主题的强度也难以一致，因此单束侧光试做版已撤下。

联系方式与简历图标采用微磁吸：指针在链接范围内移动时，图标朝指针方向偏移，合成距离最多 3px，按住时保持偏移，离开时轻轻回到中心。偏移与复位使用 260ms 的缓出曲线，不使用回弹曲线，因为几像素的位移下回弹无法察觉。主题切换按钮采用相同反馈，但最大距离为 2px，图标交替淡入淡出和主题切换行为沿用上文约定。只移动图标内容，链接与按钮的点击区域、焦点提示和布局始终固定。磁吸仅在支持悬停的精细指针且未启用“减少动态效果”时生效；触屏和键盘保留直接操作，指针离开、失焦、指针取消、标签页隐藏或能力变化时清除偏移；按下不清除偏移，点击时图标不会额外移动。

Footer 保持静止，不添加悬停或周期性动画。版权文字只参与已有的主题颜色过渡，维持页脚的低视觉权重。

## 站点标识与分享初版

- Favicon 采用 `Lo` 字母标识，已选 [Oleo Script Regular](https://github.com/google/fonts/tree/main/ofl/oleoscript)，保留柔和的曲线和厚实的笔画，字形转为 SVG 轮廓。圆角方形底色与文字色来自主题；SVG 根据浏览器的配色偏好显示深浅版本，PNG 与手机收藏图标使用浅色版本。
- 首页浏览器标签与分享标题统一为“Lo”，描述为“Lo 的个人主页，GitHub、邮箱与简历。”，不增加未经确认的个人经历文案。
- 分享卡片采用 1200 × 630px 的米白背景，主文案为“你好，我是 Lo”，下方以弱化文字色放置 `ayingott.me`，均左对齐。中文和西文字体沿用首页，主文案末尾不加句号。

## 首页结构（已确认）

- 沿用最大宽度 48rem 的内容栏，手机左右留白 1.5rem，640px 起左右留白 2.5rem；图标入口采用已选 A 方案的上下结构，首个链接容器（点击热区）左缘与标题文字框左缘对齐，不使用负 margin。
- Header 高度为 6rem，介绍区至少占据扣除 Header 和 Footer 后的动态视口高度，原有底部留白为页脚腾出空间。常规视口内介绍与图标入口组成的内容组中心约在屏幕高度的 46%；低高度窗口使用紧凑的上下留白，介绍组从 Header 下方排列，避免留白产生额外滚动。窄屏或较大字号时允许介绍区自然撑高。
- 介绍采用“你好，我是 Lo”，末尾不加句号。下方不展示说明文字。
- 标题下方依次放 GitHub、邮箱与简历三个图标链接，横向排列；GitHub 图标为 22 × 22px，信封与简历图标均为 24 × 24px、2px 描边，简历使用 Lucide `FileText`。桌面与手机的链接容器均为 36 × 36px，图标在各自容器内水平、垂直居中；GitHub 四周各留 7px，其余图标四周各留 6px，不再扩大隐形点击范围。相邻链接容器间隔 8px，图标中心相距 44px；GitHub 图标外框上缘距标题文字框下缘 13px，其余图标为 12px，作为文案的辅助入口。以上尺寸对应默认根字号，图标与容器随根字号同步缩放。
- 图标入口默认使用主题的 `--text-muted`，悬停时变为 `--text-secondary`，背景保持透明。明暗主题均沿用这组语义色，键盘操作保留焦点提示；可访问名称与原生提示文字说明链接用途，简历的可访问名称同时说明会打开新标签页。
- GitHub 使用普通网页链接，邮箱使用 `mailto:` 链接，简历提示文字为“简历（PDF）”，在新标签页打开现有 PDF 供预览；GitHub 与邮箱地址维护在 [profile.ts](../../app/utils/profile.ts)，链接展示由 [HomeLinks.vue](../../app/components/home/HomeLinks.vue) 维护。不添加其他社交入口。
- 首页仅包含首屏，不设独立链接区或第二屏。
- 内容溢出视口时（如低高度窗口或较大字号），使用浏览器原生的连续滚动，允许停在任意位置；不自动吸附、不拦截滚轮或触摸事件。Header 随文档正常滚出。此前 `proximity` 试做版在小幅滚动结束后会拉回当前屏，用户指出这一体验问题，因此取消吸附。

## 错误页

- 沿用首页的内容栏、Header 与 Footer。状态码以 `--text-muted` 等宽小字放在标题正上方，间距 8px；标题使用首页的展示字体，比首页标题小一档（`text-3xl`，640px 起 `text-4xl`），末尾不加句号：404 为“这里还没有页面”，其他状态为“页面暂时无法打开”。
- 标题下方为“回到首页”，点击后整页跳转以清除错误状态，前置 16px 的 Lucide `ArrowLeft`，作为辅助入口不使用主题的强调色与下划线：默认 `--text-muted`，悬停变为 `--text-secondary`，键盘操作显示主题焦点提示；链接左缘与标题对齐，点击区域高 44px。
- 悬停或键盘聚焦时仅箭头向左移动 2px，文字与点击区域不动，沿用首页磁吸的 260ms 缓出曲线；条件与磁吸相同，仅在支持悬停的精细指针且未启用“减少动态效果”时生效。

页面分类与首轮范围见 [产品要求](requirements.md)，主题接入与资源约定见 [架构说明](../architecture.md)。

## 站点导航（已选）

首页的 GitHub、邮箱与简历图标只承载个人信息，站点内的页面入口统一放在 Header 的导航中。

- 导航放在 Header 内，与内容栏使用相同的最大宽度和左右留白，左缘与页面标题、正文、页脚对齐；主题按钮仍在视口右侧，位置见 [已选布局](#已选布局)。
- 依次为“首页”（`/`）与“文章”（`/posts`）两个文字链接，在 Header 中垂直居中，点击区域高 44px。
- 字号为 1rem，两项间距为 24px，桌面与手机相同。以上尺寸对应默认根字号。
- 当前栏目使用 `--text-primary`，并标记 `aria-current="page"`；其余默认 `--text-muted`，悬停变为 `--text-secondary`。文章页与标签页的当前栏目为“文章”；错误页没有当前栏目。
- 键盘操作时显示主题焦点提示。

## 文章列表与标签页（已选）

文章相关页面不使用 `brutal` 风格的粗边框与硬阴影，只沿用主题的配色与字体，与首页的克制一致。

- 页面顶部留白为 2rem，640px 起为 3rem。标题“文章”使用展示字体，字号与错误页标题相同（`text-3xl`，640px 起 `text-4xl`）。
- 标题行右侧放 RSS 订阅入口，使用 Lucide `Rss` 图标（20px、2px 描边），链接 `/feed.xml`，可访问名称与提示文字为“RSS 订阅”。图标右缘与内容栏右边线对齐，44 × 44px 的点击区域向外扩展；颜色默认 `--text-muted`，悬停变为 `--text-secondary`。
- 文章按年份分组，年份以 `--text-muted` 的等宽小字（0.875rem）显示，组与组之间、标题与第一组之间相距 3rem。
- 每篇文章占一项，项与项之间相距 1.25rem：
  - 左侧为标题（1.125rem，`--text-primary`），悬停时显示 `--text-muted` 色的下划线，下划线偏移 4px。
  - 标题下方 4px 处为标签，等宽字体 0.75rem，写作 `#tag`，彼此相距 12px；默认 `--text-muted`，悬停变为 `--text-secondary`，链接到对应标签页。
  - 右侧为 `MM-DD` 格式的日期，等宽字体 0.875rem、`--text-muted`，与标题第一行基线对齐，和标题之间至少相距 24px。
  - 标题过长时在左侧换行，标签始终另起一行，手机上的结构与桌面一致。
- 没有文章时，列表页在原本放列表的位置显示“还没有文章”：正文字号、`--text-muted`，与标题相距 3rem；RSS 入口保留，便于提前订阅。标签页只为已有标签生成，没有空状态。
- 标签页 `/tags/<tag>` 使用相同的布局，标题为 `#<tag>`，不放 RSS 入口。

## 文章页（已选）

- 页面顶部留白与列表页相同。顶部不设“返回文章列表”链接，由 Header 导航承担；Header 不吸顶。
- 头部依次为：
  - 发布日期：等宽字体 0.875rem、`--text-muted`，有 `updated` 时追加“· 更新于 YYYY-MM-DD”；
  - 标题：在发布日期下方 8px，展示字体，字号与列表页标题相同；
  - 标签：在标题下方 12px，样式与列表页相同，字号为 0.875rem。
- 正文在头部下方 2.5rem 开始，使用主题的 `--reading-*` 变量：最大行宽 `--reading-measure`，字体 `--reading-font-body`，字号 `--reading-font-size`，行高 `--reading-line-height`，段落间距 `--reading-paragraph-gap`。
- 二、三级标题使用展示字体、500 字重，字号分别为 `--reading-scale-h2` 与 `--reading-scale-h3`，与上文分别相距 2.2em 和 1.8em。
- 链接使用 `--reading-link` 和 0.2em 偏移的下划线，悬停变为 `--reading-link-hover`。
- 无序列表使用实心圆点，缩进 1.25em，项间距 0.35em。
- 行内代码使用 `--reading-font-mono`，字号 0.85em，背景 `--reading-code-bg`，内边距 0.1em × 0.35em。
- 代码块使用等宽字体 0.875rem、行高 1.7，内边距 1rem × 1.25rem，背景 `--surface-elevated`，1px `--border-subtle` 边框，内容过宽时横向滚动。代码高亮的明暗配色由文章功能的实现提供。
- 引用左侧为 3px 的 `--accent-primary` 边线，左内边距 1em，文字使用 `--reading-fg-muted`。
- 图片宽度不超过正文栏、保持原始比例，带 1px `--border-subtle` 边框；图片说明为 0.875rem 的 `--text-muted` 文字，在图片下方 0.5em。

### 文章分享卡片

每篇文章在构建时生成一张 1200 × 630px 的分享卡片，配色沿用 [分享卡片初版](#站点标识与分享初版)：米白底 `#fcf6ea`，主文字 `#111111`，次要文字 `#5a5141`。

- 内边距 80px。内容自上而下：
  - 署名 `Lo · ayingott.me`：Bricolage Grotesque 400，30px，次要文字色；
  - 标题：在署名与日期之间的区域内垂直居中，左对齐；Bricolage Grotesque 与 LXGW WenKai 的 500 字重，行高 1.25，主文字色；
  - 发布日期 `YYYY-MM-DD`：Space Mono 400，28px，次要文字色。不显示更新日期与标签。
- 没有图片时，标题为 68px，最多 3 行。
- 文章填写 `image` 时：
  - 图片放在右侧宽 420px 的区域内，与文字列相距 64px；
  - 按比例缩放到不超过 420 × 470px，不裁切，在该区域内水平、垂直居中，带 1px 的 `rgba(17, 17, 17, 0.16)` 边框；
  - 标题缩小为 56px，最多 4 行。
- 标题超出行数时以省略号截断。

### 全部文章

- 文章末尾提供“全部文章”入口，链接到 `/posts`，样式与动效沿用 [错误页](#错误页) 的“回到首页”。
- 入口属于页面导航，放在正文之后、页脚之前，左缘与正文对齐，不加分隔线。
- 与正文至少相距 4rem，下方不再留白，直接接页脚，入口文字与页脚文字约相距 45px。内容较短、页面不足一屏时，入口随页脚停在视口底部，正文与入口之间以留白填充。
- Header 滚出视口后，读者在文章末尾可直接回到列表；回到顶部按钮仍负责回到页面开头。

### 回到顶部

- 只在文章页提供。文章标题滚出视口后显示，标题回到视口内时隐藏；显隐使用 180ms 的透明度过渡，隐藏时不可聚焦。用 `IntersectionObserver` 观察标题，不监听滚动事件。
- 固定在视口右下角，按钮外缘距视口右缘和下缘 1.5rem，640px 起为 2.5rem，与主题按钮图标的右边线对齐。
- 采用面板质感：44 × 44px 的圆形，背景 `--surface-elevated`，1px 描边为 `--text-primary` 14% 透明度的混色，阴影使用主题的 `--shadow-md`。按钮压在正文上方时，以此与正文区分层次。
- 内含 Lucide `ArrowUp` 图标（20px、2px 描边），默认 `--text-secondary`，悬停变为 `--text-primary`；可访问名称与提示文字为“回到顶部”，键盘操作时显示主题焦点提示。
- 点击后平滑滚动到页面顶部，启用“减少动态效果”时直接跳转；随后焦点移到 `#main-content`，不再触发额外滚动。
