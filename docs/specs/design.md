# 设计方向

更新日期：2026-09-16。

## 已选布局

首屏在桌面和手机均只承载个人介绍，滚动后才能看到其他分类。采用已选布局 1：短文案左对齐、略高于垂直中心。Footer 在整页末尾；当前没有 Footer 内容，暂不渲染。Header 放主题切换，不放左上文字标识。不提供 RSS。

主题切换入口采用 Lucide 图标按钮：显示器表示跟随系统，太阳表示浅色，月亮表示深色。图标表达已选择的偏好；跟随系统时保持显示器图标，页面明暗由系统决定。

点击单个按钮按“跟随系统 → 浅色 → 深色 → 跟随系统”循环切换，不展开菜单。按钮的提示文字与可访问名称说明当前偏好和下次点击的目标；支持 Enter/Space 激活。预渲染阶段显示同尺寸的禁用图标占位，客户端确定偏好后启用。

主题按钮背景保持透明，悬停时图标从次要文字色变为主要文字色。点击区域为 44 × 44 px，键盘操作时显示焦点提示。

颜色与字体来自 `@ayingott/theme`，默认视觉风格继续使用 `brutal`。

## 首页结构原型（待确认）

- 沿用最大宽度 48rem 的内容栏，手机左右留白 1.5rem，640px 起左右留白 2.5rem；Header、介绍和下方内容共享对齐线。
- Header 高度为 6rem，介绍区至少占据剩余动态视口高度。常规视口内介绍文字组的中心约在屏幕高度的 46%，首屏下边界才开始示例区；窄屏或较大字号时允许介绍区自然撑高。
- 介绍暂用“你好，我是 Lo。”与“在这里，记录一些想法与尝试。”，不代表正式文案。
- 首屏后依次展示“作品”“文章”，各两条静态占位示例，并标注“示例 · 待定”。分类用细线分隔，不使用卡片；桌面将分类标题与列表分列，手机上下排列。
- 当前试做分屏布局：介绍连同 Header 为第一屏，作品和文章示例各至少占一屏，内容组略高于垂直中心。各区采用最小高度，内容较多、窗口较矮或字号增大时自然撑高，仍可连续阅读。
- 滚动改为浏览器原生的连续滚动，允许停在任意位置，包括两屏之间；不自动吸附、不拦截滚轮或触摸事件。沿用整个文档的滚动条，Header 随首屏正常滚出。此前 `proximity` 试做版在小幅滚动结束后会拉回当前屏，用户指出这一体验问题，因此当前试做版取消吸附。
- 示例只供确认排版密度与滚动衔接，不设链接、独立页面或内容系统。末屏自身承载底部留白，继续不渲染 Footer。

## 待定设计

- 确认当前首屏文字位置、内容栏宽度、分屏留白及自然滚动手感；分屏方案仍是本地试做版本。
- 个人介绍正式文案、作品和文章是否保留，以及具体视觉细节后续讨论。
